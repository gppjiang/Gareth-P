# Gareth-P

Research workspace for early-life nutrition work: preclinical and clinical studies of newborn development and disease, including casein digestion and peptide release, using cell, animal, clinical and multi-omics data analysed in R and Python.

## Claude Code scientific skills

This repo ships 177 [Claude Code skills](https://docs.claude.com/en/docs/claude-code/skills) in [`.claude/skills/`](.claude/skills/README.md). Claude picks them up automatically when you open the repo in Claude Code. They include single-cell and bulk omics analysis, statistics and power calculations, metabolic modelling, mass-spectrometry and peptide tools, literature and database lookup, scientific writing, grant proposals and figure making.
